ROS 2.
Get started.

Install ROS 2 with a single command. The script detects your Ubuntu version and CPU architecture, then installs the matching ROS 2 LTS distribution using official APT packages.

This is not an official ROS 2 installer. It is provided AS IS, WITHOUT WARRANTY OF ANY KIND. Review the script before running it. The installer asks for confirmation before making changes to your system.

Install in your terminal

curl -fsSL https://get-ros2.com/install.sh | sh

Inspect. Verify. Install.

02 / SHA-256

Run the commands below on a supported Ubuntu system to download the installer and its checksum file into a temporary directory. The installer runs only if both downloads and the checksum check succeed.

Verify and install
(
  download_dir=$(mktemp -d) &&
  cd "$download_dir" &&
  curl -fsSL --proto '=https' --proto-redir '=https' \
    https://get-ros2.com/install.sh -o install.sh &&
  curl -fsSL --proto '=https' --proto-redir '=https' \
    https://get-ros2.com/install.sh.sha256 -o install.sh.sha256 &&
  sha256sum --check --strict install.sh.sha256 &&
  sh ./install.sh
)
View the SHA-256 checksum

A successful check prints install.sh: OK. If verification fails, stop and download the installer and checksum file from the same release. Do not bypass the check.

The version available on this website may differ from the latest GitHub release. To install a specific version, download both files from that release's Assets section and follow the “Verify a specific release” instructions in the README.

A checksum is not a digital signature. It verifies that the file matches the published hash, but does not independently verify the publisher's identity. Someone who can replace both files could provide a matching checksum for an altered installer.
